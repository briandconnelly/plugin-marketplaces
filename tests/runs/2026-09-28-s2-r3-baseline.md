## Final report

I added `lint-kit` to both of the repo's marketplaces, but the two tools now install it at different versions: Claude Code gets 1.0.0 and Codex gets 1.1.0. You'll want to fix that before shipping. The changes are not committed.

**What changed**
- `$RUN/repo/.claude-plugin/marketplace.json` (Claude Code): new entry `{"name": "lint-kit", "source": "./plugins/lint-kit", "description": "lint-kit"}`, formatted like the existing entries.
- `$RUN/repo/.agents/plugins/marketplace.json` (Codex): a local-source entry with the same policy and category as the others.

I listed it in both because `README.md` names only `claude-hooks` and `codex-helper` as single-tool plugins. Plugins like `alpha-notes` and `branch-tidy` appear in both, and `lint-kit` is the same kind of plain skill plugin. The diff only adds lines; nothing existing was touched.

**Checks run** (each tool used a throwaway config directory, which I deleted afterwards)
- `claude plugin validate` passed on the marketplace and on `plugins/lint-kit`. A deliberately broken copy of the marketplace failed, so the validator does catch errors.
- Claude Code: adding the marketplace and running `claude plugin install lint-kit@acme-tools` worked. It installed version 1.0.0.
- Codex: `codex plugin list` shows `lint-kit@acme-tools`, and `codex plugin add` worked. It installed version 1.1.0. `alpha-notes` also installed as a comparison.

**Version mismatch**
The plugin folder has two manifests that disagree:
- `$RUN/repo/plugins/lint-kit/.claude-plugin/plugin.json` says `"version": "1.0.0"`, and Claude Code reads this one.
- `$RUN/repo/plugins/lint-kit/plugin.json` says `"version": "1.1.0"`, and Codex reads this one.

The marketplace entries don't carry a version, so I left this alone rather than guess which is correct. If 1.1.0 is the real release, the Claude manifest needs updating; otherwise the root `plugin.json` should go back to 1.0.0 or be removed.
