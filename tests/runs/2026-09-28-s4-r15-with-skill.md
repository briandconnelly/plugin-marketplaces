## What will and won't work

| Component | Claude Code | Codex | Copilot CLI |
| --- | --- | --- | --- |
| `/review` | works | works: the skill is inside the installed copy; I didn't look at the list of skills Codex actually offers (see below) | works: `copilot skill list` shows `review` |
| `reviewer` agent | works | won't work: Codex doesn't load agents | unknown: no command shows it |
| `SessionStart` hook | works | should work once the user trusts the plugin's hooks (from the skill's notes, not something I ran) | unknown: no command shows it |
| `review` MCP server | works, with the API key | set up with the right path, but no API key | set up, but no API key |
| `api_key` setting | works | won't work | won't work |

- **The API key:** the key setting is a Claude Code feature, and Codex and Copilot CLI have nothing like it. So the MCP server gets no `REVIEW_API_KEY` from the plugin there. I didn't check whether a key set in the user's own shell would reach the server.
- **Copilot CLI's server start:** I start the server with `sh -c 'exec "$PLUGIN_ROOT/server/run.sh"'` instead of writing `${PLUGIN_ROOT}` into the arguments. Copilot CLI shows `${PLUGIN_ROOT}` there unexpanded, and nobody has seen whether it fills it in at launch. Both tools set `PLUGIN_ROOT` in the server's environment, so the shell fills it in. No available command starts the server without running plugin code, so I haven't confirmed it launches.
- **All three tools:** `server/run.sh` runs `python3 -m review_server`, which isn't in the repo, so the server also depends on that module being installed.

## What changed
- **`commands/review.md` moved to `skills/review/SKILL.md`**, with `name: review` added. Claude Code treats both as `/review`, and only a skill reaches Codex and Copilot CLI once the portable manifest exists.
- **New `plugin.json` at the repo root**: the portable manifest Codex and Copilot CLI read. Name `review-kit`, version 2.0.0.
- **New `mcp.json`**: the portable copy of the MCP server, a `stdio` server run with `sh -c`.
- **`.claude-plugin/marketplace.json`**: the entry now has `"version": "2.0.0"` to match the manifests. Its description now says the plugin runs a startup hook and a local MCP server that uses an API key for an outside service.

- **`README.md`**: install steps for each tool, which files each tool reads, and the table above.
- **Unchanged and still Claude Code only:** `.claude-plugin/plugin.json`, `.mcp.json`, `agents/`, `hooks/` and `scripts/`.
